所谓数值解法就是寻求解y(x) 在一系列离散点：

          x1 < x2 < · · · < xn < xn+1 < · · ·

上的近似值y1, y2, · · · yn, yn+1, · · · , 相邻两个节点
的距离h = xi+1 −xi 称为步长，一般情况下我们
选择等步长h。

定理1
假设单步法有p + 1 阶局部截断误差，令
y0 = y(x0)￿且f(x, y) 关于y 满足Lipschitz 条件

             |f(x, y1) −f(x, y2)| ≤L|y1 −y2|
则整体截断误差y(xn) −yn = O(hp).

--- p10 ---
如果我们用右矩形公式计算积分（即用积分下限
的值代入被积函数），就可得到

           yn+1 = yn + hf(xn+1, yn+1)

这是一个隐式的公式，称为后退的Euler 公式。
简单分析可知后退的Euler 公式的单步截断误差也
时O(h2).

--- p11 ---
如果我们用梯形公式计算积分，就可得到
  y(xn + h) = yn + hf(xn, yn) + f(xn+1, y(xn + h))
                             2

这也是一个隐式的公式，称为梯形公式。单步截断
误差是O(h3).
隐式的公式每一步需要迭代，计算量大，不便使
用。下面使用Euler 公式，来改造梯形公式，使之
成为显示的形式便于使用，称为改进的Euler 公式。
      yn+1 = yn + hf(xn, yn) + f(xn+1, yn+1)
                           2

--- p12 ---
预测：  yn+1 = yn + hf(xn, yn),
校正：  yn+1 = yn + 2[f(xn,h     yn) + f(xn+1, yn+1)]
也可以写成：


           h
yn+1 = yn + 2[f(xn, yn) + f(xn + h, yn + hf(xn, yn))]

通过泰勒展开可以得到改进的Euler 公式的局部截
断误差为O(h3), 与梯形公式的截断误差同阶，但
这里是显示公式。

--- p14 ---
Euler 公式:
function E = Euler_Method(f, a, b, n, y0)
%f: 微分方程右端函数句柄或表示函数名的字符串
% a,b: 自变量取值区间的两个端点
% n: 区间等分的个数
% y0: 函数初值y0
% E = [X′, Y′]: 自变量X 和解Y 所组成的矩阵
format long;
h = (b −a)/n;
X=zeros(1,n+1);Y=zeros(1,n+1);X=a:h:b;
Y(1)=y0;
for i=1:n
Y(i+1)=Y(i)+h*feval(f,X(i),Y(i));
end
E=[X′, Y′];

隐式Euler 公式:
function E = Im_Euler_Method(f, a, b, n, y0)
%f: 微分方程右端函数句柄或表示函数名的字符串
% a,b: 自变量取值区间的两个端点
% n: 区间等分的个数
% y0: 函数初值y0
format long;h = (b −a)/n;
X=zeros(1,n+1);Y=zeros(1,n+1);X=a:h:b;Y(1)=y0;
for i=1:n
  t=Y(i);
   for j=1:5
   t=Y(i)+h*feval(f,X(i+1),t);
  end
  Y(i+1)=Y(i)+h*feval(f,X(i+1),t);
end
E=[X′, Y′];
